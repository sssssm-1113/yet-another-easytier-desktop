## 原审查问题

| 问题 | 修复 |
| --- | --- |
| 管理员模式记录 shell PID | 仅把 nohup 简单命令置于后台，保留 exec 后的核心 PID；停止前复核进程身份 |
| EPERM 被当成进程退出 | 区分无权限与不存在，持续监测进程；旧实例事件不能删除新实例 |
| 未确认停止就显示断开 | 启停在实例串行队列执行，等待停止结果；授权取消保留实例；退出应用失败时取消退出 |
| TOML 导入截断密码、丢失字段 | 使用随包附带的 TOML 解析器；保存原始 TOML，仅合并界面实际修改的字段；保留未知字段、空节点列表、日期和大整数 |
| 迟到查询恢复连接状态 | 使用会话标识和请求代次核验异步结果，合并重复查询，防止旧退出事件污染新会话 |
| CLI 大输出死锁 | 使用受限权限的临时文件接收两个输出流，避免管道容量阻塞；超时会强制回收子进程 |
| DHCP 显示固定演示 IP | 使用核心返回的本机节点地址，未获取时显示等待分配 |
| 轮询打断输入 | 保留配置表单、搜索输入和光标；连接状态标题单独刷新 |

## 继续验证时修复

- 保存配置等待旧实例确认退出；删除网络、恢复示例和退出应用也会处理正在启动或失败后仍存活的实例。
- 导入文件对话框使用正确的超时参数，关闭弹层后返回的结果不会访问已销毁的表单。
- 管理员启停等待系统授权结果，不因界面任意超时而丢失进程控制。
- 直接启动与管理员启动都读取磁盘日志；增量读取每次最多 64 KiB，保留跨块 UTF-8 字符，界面保留最近 900 行，达到上限后继续刷新。
- 真实核心验证发现 VPN Portal 缺少必填的 `client_cidr`，已增加客户端网段字段，并保留导入值。
- 监听端口生成还需占用后续 3 个端口，因此编辑上限改为 65532。
- 关闭后重开窗口保留窗口对象；启用“断开前确认”现在实际生效。
- 构建包含新增加的配置模块、解析器和许可证；签名失败会使构建失败。
